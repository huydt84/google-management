Privacy policy: Google Management

Google Management is a personal tool used only by its owner, on the owner's own computer. Only the owner's Google account can sign in. It has no other users.

Data it accesses

  • Sign-in (openid, email): the account's email address, to check that it is the owner.
  • Gmail, read-only (gmail.readonly): headers and content of new messages, to decide which mail matters and to summarize it. It cannot send, change or delete mail.
  • Cloud Pub/Sub (pubsub): to receive "new mail" signals from Gmail in the owner's own Google Cloud project.

How it is used and where it goes

  • Mail is processed on the owner's computer. Summaries are made by a language model running locally; mail is not sent to any AI service.
  • Short notifications (sender, subject, summary and a link) are sent to the owner's own Telegram chat through the Telegram Bot API.
  • Data is not sold, shared with anyone else, or used for advertising or model training.

Storage and retention

  • Message metadata and summaries are kept in a local database on the owner's computer for 60 days, then deleted. Full message bodies are not stored.
  • The Google refresh token is stored encrypted; the key lives in the macOS Keychain.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Google Management's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
